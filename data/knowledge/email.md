# Email and calendar support

## Outlook does not open
First check the collaboration service status. If the service is healthy, ask the user to restart the app and verify the device has a supported, current client. If the issue persists, collect the app version, device name, and error text for a support ticket.

## Mail is delayed
Check the mail service status before changing local settings. Ask whether the delay affects one message or all mail. Do not request message contents unless required; metadata and a redacted error are preferred.

## Suspicious email
Do not forward suspicious attachments. Ask the user to use the organization's report-phishing control and escalate to Security Operations. The agent must not open attachments or follow links from the message.
