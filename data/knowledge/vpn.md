# VPN troubleshooting

## VPN connection fails after password reset
If a user recently changed their directory password, saved VPN credentials may be stale. Ask the user to disconnect, remove the saved VPN credential from the operating system credential manager, reconnect, and enter the new password. Never ask the user to send a password in chat. If the account is locked, route the case to Identity Support.

## VPN connects but internal sites do not load
Check the remote access service status and confirm the user is on the approved VPN profile. Ask the user to reconnect once. If internal DNS still fails, collect the device name and time of failure and create a network support ticket. Do not ask the user to disable endpoint protection.

## VPN account lockout
Do not attempt repeated sign-ins. Verify identity through the approved service desk process and hand off to Identity Support. Agents must not reset passwords or unlock accounts.
