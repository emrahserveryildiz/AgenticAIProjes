# Account and access support

## Access denied to an internal application
Confirm the application name, device, and exact error. Check the application status and the user's listed access groups using approved read-only tools. If access is missing, prepare an access request for the user's manager to approve. Never add a user to a group or bypass approval.

## Multi-factor authentication issue
Ask which approved factor is failing and whether the user still has another registered factor. Do not ask for one-time codes, recovery codes, or passwords. If all factors are unavailable, hand off to Identity Support for identity verification.
